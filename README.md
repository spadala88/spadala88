### 🔭 Professional Overview
I am a **Generative AI Engineer** focused on building autonomous agents that bridge the gap between LLMs and real-world UI interaction. I specialize in developing agents capable of navigating mobile and web interfaces, as well as high-performance RAG systems.

*   **Current Focus:** Autonomous UI Agents and Vector-based knowledge retrieval.
*   **Expertise:** LLM Orchestration, Android CLI Automation, and Embedding Search.

---

### 🤖 Featured AI Projects

#### 📱 [UI Automation Agent (Android CLI)](https://github.com/spadala88/ui_automation_agent_with_android_cli)
An advanced AI agent designed to interact with Android devices via CLI. It leverages vision and language models to understand mobile screens and execute precise commands.

#### 🧠 [UI Automation Agent](https://github.com/spadala88/UI_Automation_agent)
A core framework for building autonomous agents that can "see" and "act" on user interfaces, reducing the need for hard-coded selectors in traditional automation.

#### 📓 [Mini Notebook with Vector DB](https://github.com/spadala88/MiniNoteBookWithVectorDb)
A lightweight note-taking application powered by a Vector Database. It enables semantic search and intelligent retrieval of notes based on context rather than just keywords.
